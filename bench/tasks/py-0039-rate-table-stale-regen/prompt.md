There is a second problem waiting for you there. quote_cents walks a region's tiers in the order the table lists them and returns the first tier whose limit covers the parcel, so the tiers have to come out ascending by limit, and the generator writes them in the order the rows appear in the card. Finance appends amendment rows at the end of the file instead of editing rows in place, so a straight regeneration puts the 2 kg tier after the 30 kg one and every small parcel to an amended region gets quoted at the wrong tier. Fix the generator so the tiers it writes for each region are ascending by limit, then regenerate the table with it.

The card is finance's source of truth and must stay exactly as it is, byte for byte; if a price looks wrong to you, it is still the price. Leave quote_cents alone, the lookup itself is right, and leave the region ordering of the module as it is.
