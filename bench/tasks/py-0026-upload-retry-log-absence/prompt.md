The sync service drops connections a few times a night and one failed request currently fails the whole run. Make upload in syncer/upload.py retry: up to three attempts in total when the transport raises TransportError, no sleeping between them (the caller schedules), and after the third failure raise UploadError saying how many attempts were made. Log one line per attempt with the attempt number and whether it succeeded or failed, so ops can see retries in the shipped logs. Those logs go to a third party, so the token and the local file path must never appear in any log line or in the error message; the file's basename is fine. The tests in tests/test_upload.py cover the retry counts.
