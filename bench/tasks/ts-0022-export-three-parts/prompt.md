Three things need doing on stockctl export before the warehouse team can use it. First, names with commas or quotes in them break the CSV (the case in test/csv.test.ts fails), so fields need proper CSV quoting. Second, export needs a --since <date> option that keeps only items updated on or after that date, inclusive, so that partial syncs stop shipping the whole catalogue. Third, the exported-N-items summary line has to go to stderr instead of stdout, because people redirect stdout into a file and the line ends up inside the CSV.
