One limitation worth knowing: NFD only folds letters that decompose into ASCII + mark. Characters like `ø`, `ß`, `æ`, `đ` have no decomposition, so they're dropped as separators (`"Køben"` → `k-ben`). Handling those needs an explicit transliteration map, which I left out since the ask was accents specifically — say the word if you want it added.
