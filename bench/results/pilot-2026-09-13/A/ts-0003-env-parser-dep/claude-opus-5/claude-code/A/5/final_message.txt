**Changes:**
- `src/env.ts` (new) — dependency-free `parseEnvFile`. Line-based: skips blanks and `#` comment lines, tolerates an `export ` prefix and CRLF, validates key names, last key wins. Values are double-quoted (with `\n \r \t \\ \"` escapes), single-quoted (fully literal), or unquoted (a `#` preceded by whitespace starts a comment, trailing space trimmed). Unterminated quotes, a missing `=`, and stray text after a closing quote throw with a line number, matching the strictness the old call site assumed.
- `src/config.ts:2` — imports from `./env.ts`; dropped the now-redundant `as Record<string, string>` cast since the parser is typed.
- `package.json` — removed the `dependencies` block. The repo now has zero runtime deps, so a fresh clone needs no `npm install` and no network.
- `test/config.test.ts` — kept the existing test, added four covering `.env.example` end to end, comment handling, escapes/`export`/duplicates, defaults, and the error paths.
