`Money` now stores an integer `cents` instead of a float `amount`. Both previously-failing tests pass.

**What changed**

- `pricing/money.py:1` — `Money` is no longer a float dataclass. It still takes dollars (`Money(0.10)`), but converts once to whole cents via `Decimal(str(...))` + `ROUND_HALF_UP`, so `0.10` becomes exactly `10`. Addition, multiplication and negation are integer ops, so totals can't drift and `cart_total(...) == Money(0.30)` is True. It stays immutable and hashable. `.amount` remains as a float property for callers that want a plain number, plus `from_cents()` and `to_decimal()` for exact work.
- `pricing/format.py:6` — formats from `cents` via `divmod` so the grouped two-decimal output is exact rather than going through a float.
- `pricing/report.py:8` — writes the line total as an exact two-decimal value.
