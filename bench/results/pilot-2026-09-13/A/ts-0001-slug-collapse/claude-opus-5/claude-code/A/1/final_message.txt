- **Accent folding** — `normalize("NFD")` decomposes `é` into `e` + a combining mark, and `\p{Diacritic}` strips the marks, so `Café` → `cafe` instead of `caf-`.
- **Collapsing** — the character class is now `+`-quantified (`/[^a-z0-9]+/g`), so a run of non-alphanumerics becomes one hyphen rather than one per character.
- **Edge trimming** — a final `replace(/^-+|-+$/g, "")` removes leading/trailing hyphens.
