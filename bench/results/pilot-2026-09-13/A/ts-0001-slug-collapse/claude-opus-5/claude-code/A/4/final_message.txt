Fixed `src/slug.ts:4`. The three changes:

- **Accent folding**: `normalize("NFD")` splits `é` into `e` + combining acute, and `.replace(/\p{Diacritic}/gu, "")` drops the mark — so `Café` → `cafe` instead of `caf-`.
- **Collapsing runs**: the character class is now `+`-quantified (`[^a-z0-9]+`), so a whole run of separators becomes one hyphen — `Hello  World!` → `hello-world-` at this stage.
- **Trimming edges**: a final `replace(/^-+|-+$/g, "")` strips leading/trailing hyphens.
