**Diagnosis:** `hashKey` folds its FNV-1a result to a signed 32-bit integer (`h | 0`), so about half of all keys hash negative. `shardFor` used JS `%`, which takes the sign of the dividend, so those keys got negative indices. The range test builds random keys, so it failed roughly every other CI run.
