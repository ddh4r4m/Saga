**Root cause:** a single stray trailing space in `schema/order.json:12` — `"type": "integer "` instead of `"type": "integer"`.

The generator was fine, exactly as you suspected. It does an exact match on the type string, so `"integer "` fell through to the unknown-type branch:


That one line was buried among ~60 `warn:` lines about missing descriptions and hundreds of `debug:` self-check lines.
