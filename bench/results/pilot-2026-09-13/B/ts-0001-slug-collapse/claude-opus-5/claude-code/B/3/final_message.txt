```ts
export function slugify(input: string): string {
  // Decompose accented letters into base letter + combining mark, then drop the
  // marks so "Café" folds to "cafe" instead of losing the letter entirely.
  const folded = input.normalize("NFD").replace(/\p{M}/gu, "");
  const lowered = folded.toLowerCase();
  const replaced = lowered.replace(/[^a-z0-9]+/g, "-");
  return replaced.replace(/^-+|-+$/g, "");
}
```

- The `+` quantifier makes a run of separators produce one hyphen.
- The final replace trims hyphens from both edges, including the case where nothing survives (`slugify("---")` → `""`).
